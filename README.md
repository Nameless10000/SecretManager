# SecretManager

Десктопный менеджер секретов для Windows: **C# / .NET 10 / WinUI 3 / MVVM / SQLite**.

Приложение группирует произвольное количество полей и файлов по темам: сайтам,
приложениям и любым вашим названиям. Хранилище и переносимые резервные копии зашифрованы.

## Функции

- Мастер-пароль при запуске, ручная и автоматическая блокировка.
- Свёрнутые карточки ассоциаций, полнотекстовый поиск по названиям, поддержка кириллицы.
- Несколько слов в поиске означают «любое из слов»: `Почта Mail` найдёт обе ассоциации.
- Текст, секретные поля, PNG/JPEG и другие файлы; добавление, редактирование, удаление.
- Зона перетаскивания вложений; для картинок — вставка из буфера кнопкой и Ctrl+V.
- Копирование по нажатию, крупный предпросмотр изображений.
- Светлая, тёмная и системная тема; настройки трея, блокировки и очистки буфера.
- Зашифрованный экспорт и импорт с разрешением конфликтов.
- Встроенная краткая инструкция и FAQ.

## Архитектура

`SecretManager.Core` — модели, AES-GCM, SQLite, FTS5, сессия, импорт и слияние.
`SecretManager.App` — WinUI 3, ViewModel и Windows-интеграция.
`SecretManager.Core.Tests` — проверки криптографии и поведения хранилища.

Исходные требования и результаты проверки ведутся в [WORK_LOG.md](WORK_LOG.md).

## Установка

Скачайте **[актуальный установщик Windows x64](https://github.com/Nameless10000/SecretManager/releases/latest/download/SecretManager-Setup.exe)**.
Установка для текущего пользователя, права администратора не нужны. .NET и Windows
App SDK включены в дистрибутив. Windows 10 2004 / 19041 или новее.

Хранилище: `%LocalAppData%\SecretManager\vault.db`. Удаление приложения сохраняет
данные. Старые установщики не архивируются: существует один релиз `latest` с одним
актуальным EXE и его [SHA-256](https://github.com/Nameless10000/SecretManager/releases/latest/download/SecretManager-Setup.sha256).

## Сборка из исходников

Установите .NET SDK 10 и откройте `SecretManager.sln`. Проект использует WinUI 3;
для работы в IDE подойдёт Visual Studio с компонентами разработки Windows-приложений.
Командная сборка в Windows:

```powershell
dotnet restore SecretManager.sln
dotnet test tests/SecretManager.Core.Tests/SecretManager.Core.Tests.csproj -c Release --no-restore
dotnet build src/SecretManager.App/SecretManager.App.csproj -c Release -p:Platform=x64 --no-restore
```

`./scripts/Test-Themes.ps1` запускает отдельный WinUI-стенд с синтетическими данными:
проверяет 64 перехода между палитрами, сохранение значков, отступы анимации и уведомление
поверх списка с исчезновением через 2 секунды, 72 состояния переключателей и постоянный
темп раскрытия карточек. В том же процессе компилируется настоящий `MainWindow`:
29 сценариев входа, настроек, поиска, редактирования, блокировки диалогов, импорта,
смены пароля, удаления и возврата после отсутствия фокуса выполняются на отдельном
синтетическом профиле. Проверяется позднее завершение операции после закрытия окна.
Системный буфер обмена и интерактивные файловые диалоги этот стенд не автоматизирует.
PNG и отчёт: `artifacts/theme-checks`. В CI каждый полный процесс повторяется пять раз.
Пользовательское хранилище стенд не открывает. Эти проверки также входят в сборку установщика.

Для установщика нужен [Inno Setup 6/7](https://jrsoftware.org/isdl.php):

```powershell
./scripts/Build-Installer.ps1
```

Результат: `artifacts/installer/SecretManager-Setup.exe`. Повторная сборка заменяет
этот файл. В Git бинарники и данные не попадают. GitHub Actions запускает тесты,
собирает установщик и обновляет единственный релиз `latest` после push в `main`.

## Оформление и управление

Темы: системная, светлая, тёмная, «Полночь», «Лесная» и собственная. В редакторе:
акцент, фон, шрифт, размер, скругления и плотность. Анимации: отключены, умеренные
или максимальные. Скорость регулируется у подсветки и пружинного отклика; раскрытие
карточек и появление содержимого имеют постоянный темп. Внутренние переходы WinUI
сохраняют стандартное время. Иконки SVG контурные с прозрачным фоном.
В настройках виден предпросмотр; кнопка сохранения закрепляет изменения.

`Ctrl+L` — заблокировать, `Ctrl+F` — перейти в поиск. Крестик по умолчанию скрывает
окно в трей с немедленной блокировкой. Кнопка «Выйти» внизу слева завершает программу
полностью; выход также доступен в меню трея. Верхний замок и Ctrl+L блокируют.
Элементы бокового меню выровнены слева, быстрый доступ занимает всё место между
заголовком и нижними действиями, со своей прокруткой.
FAQ доступен в боковом меню и на экране входа. Размер текста: ползунок 10–26;
среди шрифтов доступен Comic Sans MS.

В экспорте и импорте можно выбрать ассоциации и отдельные поля. По умолчанию выбрано
всё. Для частичного переноса «Обновить выбранные поля» сохраняет остальные локальные
поля; совпадение определяется по ID, одинаковое описание не заменяет другой ID.
До разрешения всех конфликтов локальная база не меняется. Пароль экспорта: от 8
символов, мастер-пароль: от 12. Частичный формат v2 требует приложения 0.1.5 или
новее; прежние версии явно отклоняют его. Старые полные копии v1 поддерживаются.

Настройки → «Запускать при входе в Windows» включает автозапуск для текущего
пользователя через HKCU Run. Запуск происходит в трее с заблокированным хранилищем.
Windows может отключить автозапуск через диспетчер задач; приложение это не обходит.
Установка остаётся в `%LocalAppData%\Programs\SecretManager`, без прав администратора.

Установленная программа по умолчанию проверяет GitHub Releases при запуске.
Проверка читает `SecretManager-Setup.sha256` напрямую из файлов rolling-релиза,
без GitHub API и его общего лимита по IP. В файле первая строка — SHA-256 и имя EXE,
следом комментарии `# SecretManager-Version: 0.1.6` и `# SecretManager-Size: <байты>`.
Старый файл без версии показывается отдельным сообщением, отсутствие файла (404)
также не считается успешной проверкой актуальности.
Новая версия загружается по HTTPS; проверяются размер, SHA-256 из этого файла
и версия EXE. Установка ждёт блокировки хранилища и завершения процесса, затем
перезапускает приложение. Открытый редактор не прерывается. Есть отключение
автообновления и ручная проверка в настройках. Исходные/dev-сборки не обновляют себя.
Отказ сети или проверки оставляет приложение работоспособным. Параметр автообновления
хранится отдельно в `device-settings.json`; данные хранилища в запросы не включаются.
Результат установки: `%LocalAppData%\SecretManager\Updates\<id>\update-result.txt`.
Публикация сохраняет один rolling release с EXE и SHA-256; название релиза содержит
версию `SecretManager 0.1.6` и меняется после загрузки файлов. Клиент не зависит от
названия релиза. Ошибки HTTP показывают код (403/429/5xx); журнал сохраняет код
и категорию сетевой ошибки, без URL, заголовков и текста ответа.

Тесты обновлений используют подставной HTTP и отдельный синтетический установщик:
проверяют откат версии, отказы сети/хеша/размера, отмену загрузки, ожидание закрытия
родителя и передачу пути с пробелами и спецсимволами. Реальное обновление с GitHub
поверх установленной пользовательской программы этими тестами не выполняется.

В настройках есть «Открыть папку журналов»: `%LocalAppData%\SecretManager\Logs`.
`application.log` содержит время UTC, версию, названия операций, типы/HRESULT ошибок
и имена методов стека. Сообщения исключений, их Data и содержимое хранилища не пишутся.
При 256 КБ файл заменяет единственную предыдущую копию `application.previous.log`.
После аварийного завершения следующий запуск отмечает `PreviousRunInterrupted`;
принудительное завершение или отключение питания дают такую же отметку.
Для нативных сбоев дополнительно используется журнал приложений Windows.

В редакторе поля выберите «Изображение» или «Любой файл» и перетащите один файл
в выделенную зону. Для изображения и файла также доступна кнопка «Вставить из буфера».
Ctrl+V перехватывает вложение до стандартного обработчика текстового поля во всей
форме, включая описание; тип выбирается автоматически. Обычный текст остаётся
за стандартной вставкой в активное текстовое поле. Появится
предпросмотр и имя вложения. Лимиты: 10 МБ на файл, 40 Мп для изображений.
Выбор файлов использует Windows App SDK 1.8 и резервный стандартный диалог.
Запускайте приложение обычным способом: drag-and-drop в повышенном WinUI-процессе
ограничен Windows; в этом режиме доступна кнопка выбора и показывается подсказка.
Неподходящий файл не заменяет уже выбранное вложение.

В настройках есть «Только одна раскрытая ассоциация» (включено по умолчанию).
Отключите её, чтобы раскрывать несколько карточек одновременно.

## Безопасность

Названия, описания, значения, имена и base64-содержимое файлов находятся внутри
зашифрованного снимка в SQLite. Индекс поиска живёт только в памяти до блокировки.
Используется AES-256-GCM с PBKDF2-SHA256, случайными salt и nonce. Base64 сам по себе
не является шифрованием. Мастер-пароль нельзя восстановить: храните резервные копии
и пароль экспорта отдельно. Код из почты не используется.

Это начальная версия, без независимого аудита безопасности. Подробная модель угроз
и границы защиты описаны в [docs/SECURITY.md](docs/SECURITY.md).
