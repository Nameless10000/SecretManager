# SecretManager

Десктопный менеджер секретов для Windows: **C# / .NET 10 / WinUI 3 / MVVM / SQLite**.

Приложение группирует произвольное количество полей и файлов по темам: сайтам,
приложениям и любым вашим названиям. Хранилище и переносимые резервные копии зашифрованы.

## Функции

- Мастер-пароль при запуске, ручная и автоматическая блокировка.
- Свёрнутые карточки ассоциаций, полнотекстовый поиск по названиям, поддержка кириллицы.
- Текст, секретные поля, PNG/JPEG и другие файлы; добавление, редактирование, удаление.
- Копирование по нажатию, крупный предпросмотр изображений.
- Светлая, тёмная и системная тема; настройки трея, блокировки и очистки буфера.
- Зашифрованный экспорт и импорт с разрешением конфликтов.
- Встроенная краткая инструкция и FAQ.

## Архитектура

`SecretManager.Core` — модели, AES-GCM, SQLite, FTS5, сессия, импорт и слияние.
`SecretManager.App` — WinUI 3, ViewModel и Windows-интеграция.
`SecretManager.Core.Tests` — проверки криптографии и поведения хранилища.

Исходные требования и результаты проверки ведутся в [WORK_LOG.md](WORK_LOG.md).

## Безопасность

Названия, описания, значения, имена и base64-содержимое файлов находятся внутри
зашифрованного снимка в SQLite. Индекс поиска живёт только в памяти до блокировки.
Используется AES-256-GCM с PBKDF2-SHA256, случайными salt и nonce. Base64 сам по себе
не является шифрованием. Мастер-пароль нельзя восстановить: храните резервные копии
и пароль экспорта отдельно. Код из почты не используется.

Это начальная версия, без независимого аудита безопасности. Подробная модель угроз
и границы защиты описаны в [docs/SECURITY.md](docs/SECURITY.md).
