# Журнал разработки

Дата начала: 26.10.2026.

## Согласовано

- Имя приложения и публичного репозитория: SecretManager.
- .NET 10, WinUI 3 + MVVM, SQLite, Windows x64.
- Почтовый вход исключён. Локальное хранилище открывает мастер-пароль.
- Импорт объединяет данные, при конфликте пользователь выбирает действие.

## Решения

- SQLite содержит зашифрованный JSON-снимок. Вложения кодируются base64 внутри
  снимка и затем шифруются вместе с текстами и названиями.
- AES-256-GCM, PBKDF2-SHA256 (600 000 итераций), отдельные salt/nonce; проверка
  целостности до десериализации. Экспорт с отдельным паролем и контекстом шифрования.
- Индекс названий FTS5 / unicode61 строится в памяти после входа; значения не индексируются.
- Закрытие в трей по умолчанию блокирует хранилище сразу. Явный выход есть в меню трея.
- Автоблокировка отсчитывает отсутствие фокуса, включая свёрнутое/скрытое окно.
- Автоочистка буфера через 30 секунд удаляет только данные, скопированные приложением.
- Дополнено: темы Light/Dark/Midnight/Forest/Custom, редактор цветов и типографики,
  плотность и скругления, анимации Off/Medium/Maximum и скорость.
- Установщик: один актуальный SecretManager-Setup.exe, один GitHub release latest.
- NuGet-аудит выявил уязвимый SQLitePCLRaw.lib.e_sqlite3 2.1.11; использован
  Microsoft.Data.Sqlite.Core + SQLitePCLRaw.bundle_e_sqlite3 3.0.5, предупреждение устранено.
- VSTest в песочнице не смог подключиться к testhost; повторный обычный запуск
  вне песочницы прошёл: 22/22, без пропусков (26.10.2026).
- Публичный репозиторий создан, первый коммит отправлен: https://github.com/Nameless10000/SecretManager.
